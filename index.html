💡 Mecanismo de Consumo Web con fetch()

Los 4 pilares abordados en clase para comunicar nuestra aplicación frontend con un servicio web REST público.

01

Petición HTTP Asíncrona

Invocamos fetch(url) pasando el endpoint de The Rick and Morty API. El navegador inicia la solicitud sin bloquear el hilo principal y retorna una Promise.

const res = await fetch('https://rickandmortyapi.com/api/character/1');
02

Verificación de Estado HTTP

fetch() no rechaza promesas en códigos 404 o 500. Es indispensable evaluar res.ok (código 200–299) antes de procesar los datos.

if (!res.ok) throw new Error('Error HTTP: ' + res.status);
03

Deserialización del JSON

El método res.json() lee el flujo de bytes del cuerpo HTTP y retorna una segunda Promesa con el objeto JavaScript listo para usar.

const data = await res.json();
04

Renderizado Dinámico y Errores

Transformamos los datos recibidos en nodos del DOM y capturamos cualquier excepción de red o validación mediante try...catch o .catch().

try { renderizar(data); } catch (e) { mostrarError(e); }

⚔️ Comparativa de Mecanismos: async/await vs .then()

Ambos mecanismos operan sobre Promesas nativas de ECMAScript y están implementados en los botones del laboratorio superior.

✨ Enfoque 1: Sintaxis Moderna (async / await) 
async function obtenerPersonaje(id = 1) {
  const url = `https://rickandmortyapi.com/api/character/${id}`;

  try {
    // 1. Petición HTTP GET
    const res = await fetch(url);

    // 2. Validar código de estado HTTP (200-299)
    if (!res.ok) {
      throw new Error(`Estado HTTP: ${res.status}`);
    }

    // 3. Parsear flujo JSON
    const personaje = await res.json();

    // 4. Actualizar interfaz
    console.log(personaje.name, personaje.species);
  } catch (error) {
    console.error('Error capturado:', error.message);
  }
}
📜 Enfoque 2: Cadena de Promesas (.then / .catch) 
function obtenerPersonajeConPromesas(id = 1) {
  const url = `https://rickandmortyapi.com/api/character/${id}`;

  // 1. Iniciar petición fetch
  fetch(url)
    .then(res => {
      // 2. Validar respuesta HTTP
      if (!res.ok) {
        throw new Error(`Estado HTTP: ${res.status}`);
      }
      // 3. Retornar promesa de parseo JSON
      return res.json();
    })
    .then(personaje => {
      // 4. Utilizar los datos recibidos
      console.log(personaje.name, personaje.species);
    })
    .catch(error => {
      console.error('Error en la cadena:', error.message);
    });
}
